# Gemma 3 V10 held-out causal and retention assessment

State slice: `interpretability-lab-sandbox-v1`.

V10 is the next scientific packet after the passing V9 internal
qualification. Its exact design is frozen in
[`configs/gemma3-27b-heldout-causal-retention-v10-design-only.json`](../configs/gemma3-27b-heldout-causal-retention-v10-design-only.json).
It reuses only the pinned model and official feature-asset identities. It
requires a new owner-only custody root, a new external corpus, and a fresh
post-update checkpoint. V9 prompt, activation, effect, prediction, and result
bytes are not V10 inputs.

The causal stage measures a paired final-token logit-margin effect on a
document- and family-disjoint `48/48/48` fit/tune/assessment panel. Feature
selection and the expected intervention sign come from fit/tune data only and
are frozen before assessment effects are read. Every assessment row carries
the intervention, scrubbing, exact-copy, activation-only, text-only, shuffled,
constant, and matched controls. Missing rows fail closed.

The fixed causal gates are pooled transcoder FVU `<=0.05`, maximum row NMSE
`<=0.05`, cross-checkpoint feature cosine `>=0.80`, held-out mean absolute
effect `>=0.01`, held-out sign agreement `>=0.80`, scrubbing mean absolute
effect `>=0.01`, exact-copy effect `0`, control maximum `<=1.0`, and zero
attrition. Holm correction uses alpha `0.05`, three repeats, family-level
independent units, ICC assumption `0.50`, minimum standardized effect `0.50`,
and target power `0.80`; familywise power remains a planning target until
validated.

The post-update checkpoint is generated by the frozen PEFT recipe in the
packet: fit rows only, AdamW, learning rate `1e-5`, 48 steps, micro-batch one,
gradient accumulation eight, LoRA rank eight, alpha 16, zero dropout, `q_proj`
and `v_proj` targets, and seed `20260917`. Its exact manifest must be acquired
before execution. This checkpoint supports the cross-checkpoint feature
stability gate and supplies the update used by the later retention comparison.

Only after every causal gate passes does the continual-learning stage run.
It compares SGD, EWC, behavioral-only, and causal-monitor controllers on the
same ordered stream, update count, learning-progress target, and padded total
compute. The preregistered success rule is causal-monitor superiority of at
least `0.05` in prior-retention mean against every comparator while remaining
within `0.05` adaptation of each comparator, with Holm-adjusted alpha `0.05`.
Retention, adaptation, calibration error, and monitoring units are all
reported.

V10 is design-only. The packet cannot execute until the new model/checkpoint,
feature, corpus, runtime, and custody digests are populated and an independent
reviewer returns a packet-bound Ed25519 `ACCEPT`. A local signature, synthetic
run, V9 qualification, or Weco result cannot satisfy that gate. Raw prompts,
activations, logits, and per-trial outcomes may remain only in the new `0700`
custody root for 72 hours after independent validation, then must be deleted.

The intake path is implemented by
`scripts/assemble_gemma3_v10_packet.py`; it validates donor restrictions,
split counts, owner-only custody, runtime attestation, and the fit/tune
prediction lock before emitting a new digest-bound packet. The execution gate
in `scripts/check_gemma3_v10_gate.py` verifies the packet, custody manifest,
runtime, and external receipt without starting a model or provider job.
